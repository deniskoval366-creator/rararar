Детальніше про систему

Вода — основа ритуалу SHAZAY

В основі концепції SHAZAY — очищена вода, зокрема вода, що проходить алмазну фільтрацію. Вода подається через вбудовану резервуарну систему, тому для роботи SMARAGD не потрібне складне стаціонарне підключення до водопроводу.

Економне використання води

Одна з ключових особливостей SHAZAY SMARAGD — раціональне використання води під час процедур.

≈ 3,2 л/хв

Це дозволяє використовувати систему у щоденній роботі студії та раціонально витрачати воду під час процедур.

Вбудована резервуарна система

SMARAGD оснащений окремими резервуарами:

  • для чистої води;
  • для стічної води;
  • з індикатором рівня наповнення.

Резервуари легко спорожнювати, очищувати та обслуговувати. Для підтримання належного рівня гігієни система передбачає регулярне очищення та дезінфекцію резервуарів.

Душова арка Dhara

М’який потік води для повноцінного HeadSpa-ритуалу. Dhara — спеціально розроблена душова арка для процедур HeadSpa. Вона забезпечує рівномірну подачу води за заданими лініями: від зони чола через маківку до потилиці. Конструкція дозволяє використовувати арку в різних положеннях та проводити водні й олійні ритуали.

Ритуал із теплою олією

Конструкція Dhara дозволяє проводити процедури з теплою олією. Безперервний потік олії м’яко розподіляється в зоні чола та по поверхні голови, створюючи окремий розслаблювальний ритуал.

Парогенератор

У комплектацію SHAZAY SMARAGD входять парогенератор та паровий ковпак. Вони призначені для проведення парових процедур у межах HeadSpa та доглядових ритуалів.

Універсальна система для студії

SMARAGD створений не лише для HeadSpa. Завдяки функціональним насадкам система може використовуватися для:

  • процедур SHAZAY HeadSpa;
  • парових та SPA-ритуалів;
  • косметичних процедур у положенні лежачи;
  • масажу;
  • догляду за шкірою голови;
  • розслаблювальних процедур.

Що отримує студія

SMARAGD — це не просто обладнання для проведення однієї процедури. Це можливість додати до вже існуючої студії окремий преміальний HeadSpa-напрям без масштабного переоблаштування приміщення.

Завдяки автономній резервуарній системі SMARAGD можна інтегрувати у простір, де немає стаціонарного підключення до водопроводу. Саме це SHAZAY позиціонує як рішення для студій, які хочуть почати працювати з HeadSpa без великих будівельних змін.

У результаті студія отримує:

  • новий формат преміальної послуги;
  • обладнання для повноцінного HeadSpa-ритуалу;
  • можливість проводити різні види процедур;
  • гнучкість у виборі простору для встановлення;
  • готову основу для розвитку HeadSpa-напряму.

Все необхідне для процедури

SHAZAY SMARAGD об’єднує ключові компоненти, необхідні для створення повноцінного HeadSpa-ритуалу. У систему входять:

  1. резервуари для чистої та стічної води
  2. душова арка Dhara
  3. парогенератор
  4. паровий ковпак
  5. функціональні насадки
  6. система контролю рівня води

Легка інтеграція у студію

Без складного підключення. Завдяки вбудованій резервуарній системі SMARAGD може працювати без стаціонарного підключення до водопроводу. Це спрощує встановлення обладнання та дозволяє інтегрувати HeadSpa у вже функціонуючий простір студії.
